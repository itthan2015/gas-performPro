# กระบวนการและกฎธุรกิจ (Business rules)

## บทบาท
| บทบาท | รหัส | ขอบเขต | สิทธิ์หลัก |
| --- | --- | --- | --- |
| พนักงาน | emp | ตนเอง | ดูผล (ถ้า HR เปิด) · รับทราบผล · แนบเอกสารของตน |
| ผู้ประเมิน (หัวหน้าแผนก) | eval | แผนก (เลือกได้หลายแผนก) | ให้คะแนน ส่งแบบประเมิน |
| ผู้อนุมัติระดับฝ่าย | div | ฝ่าย (หลายฝ่าย) | อนุมัติ/ส่งกลับ |
| ผู้บริหาร | exec | ทั้งบริษัท | อนุมัติระดับบริหาร/ส่งกลับ |
| ฝ่ายบุคคล (HR Admin) | hr | ทั้งบริษัท | บันทึกคะแนน · จัดการพนักงาน · รอบ · สถิติ · ตั้งค่า |
| ผู้ดูแลระบบ | admin | ทั้งบริษัท | ทุกสิทธิ์ทุกเมนู |

ขอบเขตที่แก้ในหน้าจัดการพนักงานมีผลทันทีเมื่อ login ครั้งถัดไป (session อ่าน `PFormPro_app_users` ใหม่ทุกครั้ง)

## การเข้าสู่ระบบ
- พนักงาน: รหัสพนักงาน → สุ่ม 1 คำถาม (4 ตัวท้ายบัตรประชาชน / วันเกิด / 4 ตัวท้ายเบอร์) อายุ 5 นาที
- หัวหน้า/HR/admin: รหัส + รหัสผ่าน (SHA-256 + salt)
- ผิด 3 ครั้ง → ล็อก (HR ปลดล็อก) · session 6 ชม. (CacheService)
- พนักงานลาออก (active=false) เข้าระบบไม่ได้

## สายการอนุมัติ
```
ผู้ประเมินส่ง → [อนุมัติระดับฝ่าย] → อนุมัติระดับบริหาร → พนักงานรับทราบ → HR บันทึกคะแนน (done)
```
- **ข้ามขั้นฝ่าย** เมื่อ เกรด ≥ 5 **หรือ** ตำแหน่งมีคำว่า "หัวหน้าฝ่าย" **หรือ** ผู้ส่งเป็นบทบาท div (`skipDivStep`)
- นอกนั้น (รวมเกรด 4 หัวหน้าแผนก) ต้องผ่านหัวหน้าฝ่าย
- ส่งกลับแก้ไขได้ทุกขั้นอนุมัติ ต้องระบุเหตุผล → สถานะ returned
- ทุกการกระทำบันทึกใน `PFormPro_eval_history` → แสดงเป็น Timeline (ผู้ทำ บทบาท วันเวลา เหตุผล)
- HR ตั้งค่า "ให้พนักงานดูผล" เปิด/ปิด (`EMP_VIEW`) — ปิดแล้วพนักงานไม่เห็นผลและรับทราบไม่ได้

## การคิดคะแนน (แบบฟอร์ม rev.10.11.69)
- คะแนนรวม = ผลรวมคะแนนแต่ละหัวข้อ (เลือกลักษณะผล → เลือกคะแนนในช่วง ไม่ถ่วงน้ำหนัก) + การรักษาระเบียบวินัย
- ระเบียบวินัย เต็ม: เกรด 1 = 30 · เกรด 2 = 20 · เกรด 3 = 10 · เกรด 4–5 = 5 · หักตาม `SCORING.DISC_RULES` (ลาเกิน 3 วัน, มาสายเป็นชั่วโมง, ขาดงาน, ใบเตือน) ไม่ต่ำกว่า 0
- สถิติมาทำงานจัดการโดย HR (เมนูสถิติมาทำงาน / นำเข้า CSV) ผู้ประเมินแก้ไม่ได้ · บันทึกแล้วคำนวณแบบประเมินที่ยังไม่ done ใหม่
- เกรด 1–3: A+ ≥95 · A 85–94.99 · B+ 80 · B 75 · C … F (`SCORING.GR_NEW`) · เกรด 4–5: 5 ≥90 … 1 (`GR_SUP`)
- ปัดทศนิยม 2 ตำแหน่งก่อนตัดเกรด · ตัวอย่างคำนวณอยู่ในเมนู Help?

## สถานะพนักงาน
- isactive = false เมื่อ remark มี "#ลาออก" / แผนก "ลาออก" / ไม่อยู่ใน PersonalActive.json
- ลาออก → active=false, evaluate=false (ไม่รับประเมิน) — trigger ในฐานข้อมูล
- ทุกหน้ารายชื่อมีตัวกรอง ปกติ / ลาออก / ทั้งหมด (ค่าเริ่มต้น = ปกติ)

## รอบการประเมิน
- เปิดใช้ได้ทีละ 1 รอบ (`is_active`) · HR/admin เพิ่ม/แก้/เปิด/ลบ (ลบได้เฉพาะรอบปิดที่ไม่มีแบบประเมิน)
- ผลประเมินฉบับก่อนหน้า = รอบที่ done แสดงตามหัวข้อของแบบฟอร์มเดิม (ข้อมูลเก่าไม่ถูกแปลง)
